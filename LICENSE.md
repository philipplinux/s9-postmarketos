# ⚖️ Licence

![Status: Proposed MIT](https://img.shields.io/badge/licence-Proposed_MIT-64748b)

**Proposed MIT** — the project's APKBUILD metadata uses `license="MIT"`. This page sets out that proposed basis for a repository-level licence.

If adopted, the MIT terms provide:

| | Summary |
| --- | --- |
| ✅ Permissions | Use, copy, modify, distribute, sublicense and sell the covered software |
| 📝 Condition | Preserve the copyright and permission notice |
| 🛡️ Limitations | No warranty; liability is limited by the licence text |

The maintainer must confirm the copyright notice and covered scope before adoption. Kernel components, firmware, dependencies and artwork retain their existing third-party terms.
